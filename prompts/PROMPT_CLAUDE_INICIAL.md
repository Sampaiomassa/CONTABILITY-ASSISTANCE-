# Prompt inicial para Claude Code

Você é o desenvolvedor principal sênior deste projeto.

Leia primeiro:

1. `ARQUIVO_MESTRE.md`
2. `README.md`
3. `index.html`

Regras obrigatórias:

- O Assistente Contábil é um projeto 100% independente: não depende de nenhuma IA, API externa ou serviço de terceiros para funcionar.
- Uma camada opcional e futura de integrações poderá ser plugada via BANKS (hub de API keys do cliente, projeto à parte). Isso nunca é pré-requisito para o funcionamento do produto.
- Não armazenar senha GOV.br, e-CAC, prefeitura ou credenciais sensíveis.
- Não hardcodar API keys.
- Não fazer refatoração gigante sem análise prévia.
- Primeiro faça diagnóstico do `index.html` atual.
- Depois proponha uma evolução por fases curtas.

Tarefa inicial:

Analise o projeto atual e entregue um relatório com:

1. estrutura atual do HTML;
2. funcionalidades já existentes;
3. riscos de segurança;
4. pontos que precisam ser removidos ou substituídos;
5. como transformar o HTML em produto multiempresa funcional;
6. como separar dados por contabilidade e cliente;
7. quais módulos devem virar prioridade no MVP;
8. quais mudanças fazer primeiro sem quebrar o arquivo atual;
9. quais testes manuais devem ser feitos após cada etapa.

Nesta primeira etapa, NÃO altere arquivos. Apenas analise.
